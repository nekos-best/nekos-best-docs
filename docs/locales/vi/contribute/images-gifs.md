# Đóng góp Hình ảnh & GIF

## Yêu cầu đối với nội dung đóng góp

1. **Chất lượng cao:** Hình ảnh và GIF phải rõ nét, không bị mờ hay nén quá mức.
2. **Hoàn toàn SFW:** Chỉ chấp nhận nội dung Safe For Work (SFW).
3. **Ghi nhận tác giả:** Vui lòng cung cấp tên họa sĩ và link nguồn gốc nếu có.
4. **Quy trình gửi:** Bạn có thể tham gia [Máy chủ Discord](https://nekos.best/discord?ref=docs) của chúng tôi và chia sẻ trong kênh đóng góp hoặc tạo Pull Request trên kho lưu trữ GitHub của chúng tôi.
