# よくある質問 (FAQ)

以下は、最もよく寄せられる質問のリストです。

## 全般

#### サーバーはどこにありますか？
> サーバーはドイツでホスティングされています。

#### API の信頼性はどのくらいですか？
> 当社の API は現在、年間**少なくとも** 99.99% 以上の稼働率を維持しています。

#### API を使用する際にクレジット表記（帰属表示）は必要ですか？
> いいえ、クレジット表記は必須ではありませんが、記載していただけると幸いです。

## 画像 & GIF

#### 画像や GIF はどのくらい安全（SFW）ですか？
> 私たちは全年齢対象（SFW）のコンテンツを最優先しています。他の多くのアニメ API とは異なり、性的示唆を含む衣装（水着、ビキニ、下着、シースルー、露出度の高い服など）を着たキャラクターは含まれていません。\
> さらに、パンチラ（意図的に下着が見えている構図）や脇フェチを狙った構図、その他フェチ向けのコンテンツも除外しています。\
> 単なる量の多さではなく、安全で高品質なコンテンツを提供するため、すべての画像と GIF を慎重に選定しています。

#### 画像や GIF を商用利用できますか？
> いいえ。[利用規約](/legal/tos)に記載されているとおり、商用利用は禁止されています。\
> 画像の著作権は当社に帰属しておらず、原作者への適切なクレジットを明記した上で、純粋に娯楽目的で共有されています。

#### 原作者のクレジット表記を含める必要がありますか？
> クレジット表記は必須ではありませんが、API がすでにこの情報を提供しているため、記載することを強く推奨します。

#### 画像や GIF の出典（ソース）が誤っている、または欠落しています。どこに報告すればよいですか？
> API 内で誤った出典や欠落している出典を見つけた場合は、Discord サーバーにてご報告ください。`#api-support` チャンネルに移動し、新しい投稿を作成してください。

#### API に X を追加してもらえますか？
> カテゴリーの提案は、専用の `#suggestions` チャンネルがある Discord サーバー経由で送信してください。
>
> **注:** SFW カテゴリーの提案のみが受け付けられます。「なめる（lick）」や「誘拐（kidnap）」などのコンテンツを含む提案は、当社の SFW ガイドラインに適合しないため拒否されます。

#### 新しい画像、GIF、またはカテゴリーはいつ追加されますか？
> 固定の公開スケジュールや完了予定時間（ETA）はありません。すべてのコンテンツは手動で追加されており、準備が整い、管理者が対応できる個人時間が確保できたタイミングでアップデートが行われます。

#### API に画像や GIF を提供できますか？
> もちろんです。貢献したい場合は、Discord サーバーに参加し、`#api-support` で投稿を作成してください。\
> 貢献者には、Discord コミュニティで特別な Contributor ロールが付与されます。

#### API 内に AI 生成の画像や GIF は含まれていますか？
> いいえ。API 内のすべての画像および GIF は人間の絵師によって作成されています。AI 生成コンテンツは一切サポートしていません。

## デバッグ / エラー

#### なぜ ERR-C コード "NB-BXIUA" が発生するのですか？
> 空の `User-Agent` ヘッダーは 2024 年 8 月以降ブロックされていますが、2026 年 6 月に新しいフォーマットガイドラインが導入されました。ライブラリのデフォルト値や誤ったフォーマットを使用するとリクエストが自動的に拒否される可能性があるため、要求されたフォーマットに必ず従ってください。設定が正しいか確認するために、[User-Agent ドキュメント](/ja/getting-started/api-reference.html#user-agent)をご参照ください。

#### VPN またはプロキシを使用していますが、リクエストが送信できなくなりました。
> VPN やプロキシの使用は許可されていますが、いくつかの重要な制限があります。それらの IP アドレスは多数のユーザー間で共有されているため、たった 1 人の悪意あるユーザーによって IP が BAN され、同じ IP を使用する全員に影響が及ぶ可能性があります。BAN された VPN/プロキシ IP は例外なく永久にブロックされ、通常の IP よりもはるかに高い割合でフラグが立てられます。VPN/プロキシに依存していてアクセスできなくなった場合、残念ながら当社で対応できることはありません。
