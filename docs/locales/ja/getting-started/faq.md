# よくある質問 (FAQ)

よく寄せられる質問と回答をまとめています。

## 全般

#### サーバーはどこにありますか？
> サーバーはドイツでホスティングされています。

#### API の信頼性はどのくらいですか？
> 年間**最低でも** 99.99% 以上の稼働率を維持しています。

#### API を使用する際にクレジット表記は必要ですか？
> いいえ、必須ではありませんが、記載していただけると嬉しいです。

## 画像 & GIF

#### 画像や GIF はどのくらい安全（SFW）ですか？
> 私たちは完全な全年齢向け（SFW）コンテンツであることを最優先しています。他の多くのアニメ API とは異なり、性的な示唆を含む衣装（水着、ビキニ、下着、透け感のある服、露出度の高い服など）を着たキャラクターは掲載していません。\
> さらに、パンチラ（意図的に下着が見える構図）や脇を強調したフェチ向けの構図なども除外しています。\
> 単純な点数ではなく、安全で高品質なコンテンツを届けるため、すべての画像・GIF を慎重に選定しています。

#### 画像や GIF を商用利用できますか？
> いいえ。[利用規約](/legal/tos)に定めるとおり、商用利用は禁止されています。\
> これらの画像の権利は私たちに帰属しておらず、原作者への適切なクレジットを明記したうえで、純粋に娯楽目的で共有しています。

#### 作者のクレジット表記は必須ですか？
> 必須ではありませんが、API のレスポンスに作者情報が含まれているため、記載することを強くおすすめします。

#### 画像や GIF の出典が誤っている、または欠落しています。どこに報告すればよいですか？
> 誤った出典や欠落している出典を見つけた場合は、Discord サーバーの `#api-support` チャンネルに新しい投稿を作成してご報告ください。

#### API に新しいカテゴリを追加してもらえますか？
> カテゴリの提案は、Discord サーバーの専用チャンネル `#suggestions` からお寄せください。
>
> **注:** 受け付けているのは SFW カテゴリのみです。「なめる（lick）」や「誘拐（kidnap）」など、SFW ガイドラインに反する提案は却下されます。

#### 新しい画像・GIF・カテゴリはいつ追加されますか？
> 決まった公開スケジュールや予定時期（ETA）はありません。すべてのコンテンツは手動で追加しているため、準備が整い運営メンバーの時間が確保できたタイミングで更新しています。

#### API に画像や GIF を提供できますか？
> もちろんです。ご協力いただける場合は、Discord サーバーに参加のうえ `#api-support` チャンネルに投稿を作成してください。
> ご協力いただいた方には、Discord コミュニティで特別な Contributor ロールを付与しています。

#### API 内に AI 生成の画像や GIF は含まれていますか？
> いいえ。API で配信している画像・GIF はすべて人間のクリエイターによる作品です。AI 生成コンテンツは扱っていません。

#### 画像や GIF を AI・機械学習・LLM の学習データに使えますか？
> **いいえ。**[利用規約](/legal/tos)に記載のとおり、API のコンテンツを AI・機械学習・LLM モデルの学習に利用する行為（スクレイピングやデータセットの収集を含む）は固く禁止されており、違反した場合は API の利用が停止（BAN）されます。私たちはコンテンツの著作権者ではないため、利用許可を出すこともできません。

#### 画像や GIF のキャッシュ、ダウンロード、スクレイピングはできますか？
> **JSON API レスポンス**（メタデータや URL など）のキャッシュは、公開や再配布を行わない**私的利用**に限り許可されています。\
> 一方、**画像や GIF アセット本体**のキャッシュ、ダウンロード、スクレイピング、再ホスティング、または一括抽出は[利用規約](/legal/tos)で**固く禁止**されており、違反した場合は API の利用が停止（BAN）されます。

#### GIF のファイルサイズはどれくらいですか？
> 高速に読み込めるよう軽量化・最適化しており、1 ファイルあたり平均 **約 900 KB** に抑えています。

## デバッグ / エラー

#### ERR-C コード "NB-BXIUA" が返るのはなぜですか？
> 空の `User-Agent` ヘッダーや偽装された `User-Agent` ヘッダーはブロックされます。有効な `User-Agent` ヘッダーを送信し、ブラウザ文字列の偽装や既知のクローラーへのなりすましを避けてください。推奨フォーマットについては [User-Agent ドキュメント](/ja/getting-started/api-reference.html#user-agent)をご確認ください。

#### ERR-C コード "NB-BCFSD" が返るのはなぜですか？
> `NB-BCFSD` は、自動不正検出システムによって API の利用が停止（BAN）されたことを示します。誤検知と思われる場合は、[Discord サーバー](https://nekos.best/discord)または **[contact@nekos.best](mailto:contact@nekos.best)** までご連絡ください。

#### ERR-C コード "NB-BXASN" が返るのはなぜですか？
> `NB-BXASN` は、ご利用の ASN（自律システム番号）がシステム側でブロックされていることを示します。リクエストを送信するには、IP アドレスのホワイトリスト登録が必要です。[Discord サーバー](https://nekos.best/discord)または **[contact@nekos.best](mailto:contact@nekos.best)** までお問い合わせください。

#### VPN やプロキシを使っていますが、リクエストできなくなりました。
> VPN やプロキシの利用自体は許可していますが、重要な注意点があります。IP アドレスが多数のユーザー間で共有されているため、たった 1 人の悪質な利用によってその IP がブロックされ、同じ IP を使う全員が影響を受けることがあります。ブロックされた VPN／プロキシの IP は例外なく永久にブロックされ、通常の IP よりもはるかに高い確率で検知されます。VPN やプロキシ経由でアクセスできなくなった場合、残念ながらこちらで解除することはできません。
