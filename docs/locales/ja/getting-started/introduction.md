# はじめに

## NEKOSBEST について

**NEKOSBEST** 公式開発者ドキュメントへようこそ。

私たちは **2021 年 2 月**から運営を続けており、さまざまなカテゴリの高品質で全年齢向け（SFW）なアニメ画像・GIF を低遅延で配信しています。
