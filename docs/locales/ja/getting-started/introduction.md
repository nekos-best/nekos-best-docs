# 概要

## 当サービスについて

**NEKOSBEST** 公式開発者ドキュメントへようこそ。

当サービスは **2021年2月** より運営されており、低遅延で高品質かつ全年齢対象（SFW）のアニメ画像・GIFを提供しています。
