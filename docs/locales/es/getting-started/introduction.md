# Introducción

## Sobre nosotros

¡Hola! Te damos la bienvenida a la documentación para desarrolladores de **NEKOSBEST**.

Llevamos activos desde **febrero de 2021** ofreciendo imágenes y GIFs de anime de alta calidad, aptos para todo público (SFW), en una gran variedad de categorías y con baja latencia.
