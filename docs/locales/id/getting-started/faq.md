# Pertanyaan Umum (FAQ)

Berikut adalah beberapa pertanyaan yang paling sering diajukan.

## Umum

#### Di mana lokasi server?
> Server di-host di Jerman.

#### Seberapa andal API ini?
> API kami saat ini mempertahankan waktu aktif (uptime) **setidaknya** 99,99% setiap tahunnya.

#### Apakah atribusi diperlukan untuk menggunakan API?
> Tidak, atribusi tidak diwajibkan, tetapi sangat dihargai.

## Gambar & GIF

#### Seberapa aman gambar dan GIF yang ada?
> Kami mengutamakan konten yang sepenuhnya aman untuk tempat kerja (SFW). Berbeda dari banyak API anime lainnya, Anda tidak akan menemukan karakter dalam pakaian bernuansa seksual (misalnya pakaian renang, bikini, pakaian dalam, pakaian transparan, atau pakaian serba terbuka).\
> Selain itu, kami mengecualikan konten seperti panty shots (di mana pakaian dalam sengaja diperlihatkan), "bait" berfokus pada ketiak, dan konten berorientasi fetish serupa.\
> Setiap gambar dan GIF dipilih dengan cermat untuk memastikan konten yang aman dan berkualitas tinggi daripada sekadar kuantitas.

#### Bisakah saya menggunakan gambar atau GIF secara komersial?
> Tidak. Penggunaan komersial dilarang sebagaimana tercantum dalam [Syarat dan Ketentuan](/legal/tos).\
> Gambar tidak dimiliki oleh kami dan dibagikan murni untuk tujuan hiburan, dengan kredit yang sesuai kepada kreator asli.

#### Apakah saya diwajibkan mencantumkan kredit seniman?
> Meskipun Anda tidak diwajibkan untuk mencantumkan kredit seniman, kami sangat menyarankannya karena API telah menyediakan informasi ini.

#### Ada sumber yang salah atau hilang pada gambar atau GIF. Di mana saya harus melaporkannya?
> Jika Anda menemukan sumber yang salah atau hilang di API, silakan laporkan di server Discord kami. Buka saluran `#api-support` dan buat postingan baru.

#### Bisakah Anda menambahkan X ke API?
> Saran kategori harus dikirimkan melalui server Discord kami, di mana kami memiliki saluran khusus untuk `#suggestions`.
>
> **Catatan:** Hanya saran kategori SFW yang diterima. Saran yang melibatkan konten seperti menjilat atau menculik tidak sesuai dengan pedoman SFW kami dan akan ditolak.

#### Kapan gambar, GIF, atau kategori baru akan dirilis?
> Tidak ada jadwal rilis tetap atau ETA. Semua konten ditambahkan secara manual, dan pembaruan dilakukan saat sudah siap serta saat pemilik memiliki waktu luang.

#### Bisakah saya menyumbangkan gambar atau GIF ke API?
> Tentu saja. Jika Anda ingin berkontribusi, silakan bergabung dengan server Discord kami dan buat postingan di `#api-support`.\
> Kontributor menerima peran Contributor khusus di komunitas Discord kami.

#### Apakah ada gambar atau GIF hasil buatan AI di API?
> Tidak. Semua gambar dan GIF dalam API dibuat oleh seniman manusia. Kami tidak mendukung konten buatan AI.

## Penanganan Masalah

#### Mengapa saya mendapatkan kode ERR-C "NB-BXIUA"?
> Meskipun header `User-Agent` yang kosong telah diblokir sejak Agustus 2024, pedoman format baru telah diperkenalkan pada Juni 2026. Pastikan untuk mengikuti format yang diminta, karena menggunakan default pustaka atau format yang salah dapat menyebabkan permintaan Anda ditolak secara otomatis. Silakan tinjau [dokumentasi User-Agent](/id/getting-started/api-reference.html#user-agent) kami untuk memastikan pengaturan Anda benar.

#### Saya menggunakan VPN atau proxy, tetapi sekarang tidak bisa membuat permintaan lagi.
> VPN dan proxy diizinkan, tetapi memiliki beberapa batasan penting. Alamat IP mereka dibagikan di antara banyak pengguna, yang berarti satu pengguna bermasalah dapat menyebabkan IP diblokir dan berdampak pada pengguna lain. IP VPN/proxy yang diblokir bersifat permanen tanpa pengecualian, dan ditandai dengan tingkat yang jauh lebih tinggi daripada IP biasa. Jika Anda bergantung pada VPN/proxy dan kehilangan akses, sayangnya tidak ada yang bisa kami lakukan.
