# Pustaka Tidak Resmi

---

Pustaka yang ditautkan di bawah ini dibuat oleh kontributor pihak ketiga. Meskipun kami memeriksa kualitas kode mereka selama pengajuan, kami tidak dapat menjamin keamanan atau pemeliharaannya.

Jika ada masalah dengan contoh atau pemeliharanya, silakan [buka issue baru](https://github.com/nekos-best/nekos-best-docs/issues/new?labels=e-issue,d-issue) di repositori kami. Jika Anda mengalami kesulitan saat menggunakan contoh, hubungi pemeliharanya atau bergabunglah dengan [server Discord](https://nekos.best/discord?ref=docs).
