# คำถามที่พบบ่อย (FAQ)

ด้านล่างนี้คือคำถามที่พบบ่อยที่สุดพร้อมคำตอบ

## ทั่วไป

#### เซิร์ฟเวอร์ตั้งอยู่ที่ไหน?
> เซิร์ฟเวอร์ตั้งอยู่ที่ประเทศเยอรมนี

#### API มีความเสถียรแค่ไหน?
> ปัจจุบัน API ของเรามี uptime **อย่างน้อย** 99.99% ต่อปี

#### จำเป็นต้องให้เครดิตเมื่อใช้งาน API ไหม?
> ไม่จำเป็นต้องให้เครดิต แต่ถ้าช่วยลงเครดิตให้ เราจะขอบคุณมาก

## รูปภาพ & GIF

#### รูปภาพและ GIF ปลอดภัยแค่ไหน?
> เราให้ความสำคัญกับเนื้อหาที่ปลอดภัย (SFW) 100% แตกต่างจากอนิเมะ API ทั่วไปตรงที่คุณจะไม่เจอตัวละครในชุดวาบหวิวหรือส่อไปทางเพศ (เช่น ชุดว่ายน้ำ บิกินี ชุดชั้นใน เสื้อผ้าซีทรู หรือชุดที่เปิดเผยเกินควร)\
> นอกจากนี้ เรายังคัดกรองเนื้อหาอย่างมุมเสยเห็นชุดชั้นใน (panty shots), ภาพเน้นรักแร้เพื่อดึงดูดสายตา และเนื้อหาแนว fetish อื่นๆ ออกทั้งหมด\
> รูปภาพและ GIF ทุกรายการผ่านการคัดเลือกอย่างพิถีพิถัน โดยเน้นความปลอดภัยและคุณภาพมากกว่าปริมาณ

#### นำรูปภาพหรือ GIF ไปใช้ในเชิงพาณิชย์ได้ไหม?
> ไม่ได้ ห้ามนำไปใช้ในเชิงพาณิชย์ตามที่ระบุไว้ใน [ข้อกำหนดในการให้บริการ](/legal/tos)\
> เราไม่ได้เป็นเจ้าของลิขสิทธิ์รูปภาพเหล่านี้ และนำมาแบ่งปันเพื่อความบันเทิงเท่านั้น โดยให้เครดิตแก่ผู้สร้างผลงานต้นฉบับอย่างเหมาะสม

#### จำเป็นต้องแสดงเครดิตของนักวาดไหม?
> แม้จะไม่ได้บังคับให้แสดงเครดิตของนักวาด แต่เราแนะนำอย่างยิ่งให้แสดงไว้ เนื่องจาก API ส่งข้อมูลส่วนนี้มาให้อยู่แล้ว

#### พบข้อมูลแหล่งที่มาของรูปภาพหรือ GIF ผิดพลาดหรือขาดหายไป ต้องแจ้งที่ไหน?
> หากพบแหล่งที่มาที่ผิดหรือขาดหายไปใน API สามารถแจ้งได้ที่เซิร์ฟเวอร์ Discord ของเรา โดยเข้าไปที่ห้อง `#api-support` แล้วสร้างโพสต์ใหม่

#### ขอให้เพิ่มหมวดหมู่ X เข้ามาใน API ได้ไหม?
> สามารถเสนอหมวดหมู่ใหม่ได้ทางเซิร์ฟเวอร์ Discord ของเรา ในห้อง `#suggestions` โดยเฉพาะ
>
> **หมายเหตุ:** เรารับเฉพาะข้อเสนอหมวดหมู่ที่เป็น SFW เท่านั้น ข้อเสนอที่เกี่ยวกับเนื้อหาอย่าง `lick` หรือ `kidnap` ไม่สอดคล้องกับแนวทาง SFW ของเราและจะถูกปฏิเสธ

#### รูปภาพ GIF หรือหมวดหมู่ใหม่จะอัปเดตเมื่อไหร่?
> ไม่มีตารางเวลาปล่อยอัปเดตหรือ ETA ที่แน่นอน เนื้อหาทั้งหมดถูกเพิ่มด้วยมือ และจะอัปเดตเมื่อพร้อมและเมื่อผู้ดูแลมีเวลาว่างในการจัดการ

#### ฉันสามารถส่งรูปภาพหรือ GIF มาร่วมสมทบใน API ได้ไหม?
> ได้เลย หากต้องการร่วมส่งผลงาน สามารถเข้าร่วมเซิร์ฟเวอร์ Discord ของเราและสร้างโพสต์ในห้อง `#api-support`
> ผู้ร่วมสมทบจะได้รับยศ Contributor พิเศษในคอมมูนิตี้ Discord ของเราด้วย

#### ใน API มีรูปภาพหรือ GIF ที่สร้างด้วย AI ไหม?
> ไม่มี รูปภาพและ GIF ทั้งหมดใน API สร้างสรรค์โดยนักวาดที่เป็นมนุษย์ เราไม่รองรับเนื้อหาที่สร้างด้วย AI

#### นำรูปภาพหรือ GIF ไปใช้เทรน AI, ML หรือ LLM ได้ไหม?
> **ไม่ได้** ตามที่ระบุไว้ใน [ข้อกำหนดในการให้บริการ](/legal/tos) ห้ามนำเนื้อหาจาก API ไปใช้ฝึกโมเดล AI, machine learning หรือ LLM (รวมถึงการ scrape หรือรวบรวมเป็นชุดข้อมูล) โดยเด็ดขาด และจะส่งผลให้ถูกแบนจากการใช้งาน API ทั้งนี้เราไม่สามารถอนุญาตให้ใช้ได้ เนื่องจากเราไม่ได้เป็นเจ้าของลิขสิทธิ์เนื้อหาดังกล่าว

#### สามารถ cache, ดาวน์โหลด หรือ scrape รูปภาพหรือ GIF ได้ไหม?
> สามารถ cache **JSON response จาก API** (เช่น metadata และ URL) สำหรับ**การใช้งานส่วนตัว**เท่านั้น ตราบใดที่ไม่ได้นำไปเผยแพร่ต่อสาธารณะหรือแจกจ่ายต่อ\
> ห้าม cache, ดาวน์โหลด, scrape, rehost หรือดึง**ไฟล์รูปภาพหรือ GIF จริง**ออกเป็นจำนวนมาก**โดยเด็ดขาด** ตามที่ระบุใน [ข้อกำหนดในการให้บริการ](/legal/tos) มิฉะนั้นจะถูกแบนจากการใช้งาน API

#### ไฟล์ GIF มีขนาดใหญ่แค่ไหน?
> ไฟล์ GIF ของเราถูกปรับให้มีขนาดเล็กและโหลดได้รวดเร็ว โดยมีขนาดเฉลี่ยอยู่ที่ประมาณ **~900 KB** ต่อไฟล์

## การดีบัก / ข้อผิดพลาด

#### ทำไมถึงได้รหัส ERR-C "NB-BXIUA"?
> ระบบจะบล็อก `User-Agent` header ที่ว่างเปล่าหรือปลอมแปลง ตรวจสอบให้แน่ใจว่าคำขอของคุณแนบ `User-Agent` header ที่ถูกต้อง รวมถึงไม่ปลอมแปลงสตริงของเบราว์เซอร์หรือแอบอ้างเป็น crawler ที่รู้จักกันทั่วไป ดูรูปแบบที่แนะนำได้ที่ [เอกสาร User-Agent](/th/getting-started/api-reference.html#user-agent)

#### ทำไมถึงได้รหัส ERR-C "NB-BCFSD"?
> `NB-BCFSD` หมายความว่าคุณถูกแบนจาก API โดยระบบตรวจจับการใช้งานผิดวัตถุประสงค์อัตโนมัติของเรา หากเชื่อว่าเกิดจากความผิดพลาด สามารถติดต่อเราได้ทาง [เซิร์ฟเวอร์ Discord](https://nekos.best/discord) หรือส่งอีเมลมาที่ **[contact@nekos.best](mailto:contact@nekos.best)**

#### ทำไมถึงได้รหัส ERR-C "NB-BXASN"?
> `NB-BXASN` หมายความว่า ASN (Autonomous System Number) ของคุณถูกแบนในระบบของเรา หากต้องการส่งคำขอได้ จำเป็นต้องนำ IP address ของคุณเข้า whitelist ก่อน กรุณาติดต่อเราผ่านทาง [เซิร์ฟเวอร์ Discord](https://nekos.best/discord) หรือส่งอีเมลมาที่ **[contact@nekos.best](mailto:contact@nekos.best)**

#### ฉันใช้ VPN หรือ proxy แต่ตอนนี้ส่งคำขอไม่ได้แล้ว
> เราอนุญาตให้ใช้ VPN และ proxy ได้ แต่มีข้อจำกัดสำคัญอยู่ เนื่องจาก IP address เหล่านี้ถูกใช้งานร่วมกันหลายคน หากมีผู้ใช้เพียงคนเดียวทำผิดกติกาจน IP ถูกแบน ก็จะส่งผลกระทบต่อผู้ใช้คนอื่นทั้งหมดที่ใช้ IP เดียวกัน IP ของ VPN/proxy ที่ถูกแบนจะถูกบล็อกถาวรโดยไม่มีข้อยกเว้น และมีโอกาสถูกตรวจจับสูงกว่า IP ทั่วไปมาก หากคุณใช้งานผ่านช่องทางดังกล่าวแล้วถูกตัดสิทธิ์ ขออภัยที่เราไม่สามารถดำเนินการแก้ไขให้ได้
