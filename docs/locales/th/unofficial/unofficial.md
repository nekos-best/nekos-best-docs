# ไลบรารีที่ไม่เป็นทางการ

---

ไลบรารีที่เชื่อมโยงไว้ด้านล่างสร้างขึ้นโดยผู้ร่วมพัฒนาภายนอก แม้เราจะตรวจสอบคุณภาพโค้ดในขั้นตอนการส่งเข้ามา แต่เราไม่สามารถรับประกันความปลอดภัยหรือการดูแลรักษาในระยะยาวได้

หากพบปัญหาเกี่ยวกับตัวอย่างหรือผู้ดูแล สามารถ [เปิด issue ใหม่](https://github.com/nekos-best/nekos-best-docs/issues/new?labels=e-issue,d-issue) ใน repository ของเราได้ หรือหากติดปัญหาในการใช้งานตัวอย่าง ให้ติดต่อผู้ดูแลไลบรารีนั้นโดยตรงหรือเข้าร่วม [เซิร์ฟเวอร์ Discord](https://nekos.best/discord?ref=docs)
