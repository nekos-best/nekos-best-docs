# إضافة أمثلة برمجة جديدة

## إرشادات المساهمة لأمثلة البرمجة

* يجب أن تكون المشاركات **مكتوبة باللغة الإنجليزية**.
* وثق مثالك بأكبر قدر ممكن من التفصيل.
* تأكد من أن الكود الخاص بك يعمل وقد تم اختباره بشكل صحيح.

### نحتفظ بالحق في:

* تعديل مشاركتك بعد تقديمها.
* إزالة مشاركتك إذا لزم الأمر.

## إنشاء مثال برمجي جديد

### 1. قم بعمل Fork لهذا المستودع

### 2. قم باستنسخ الـ Fork الخاص بك واستخدم `cd` للانتقال إلى دليل المشروع

### 3. قم بتثبيت VitePress

يمكنك العثور على متطلبات VitePress الأساسية في [التوثيق الرسمي](https://vitepress.dev/guide/getting-started#prerequisites).

::: code-group

```sh [npm]
npm add -D vitepress@next
```

```sh [pnpm]
pnpm add -D vitepress@next
```

```sh [yarn]
yarn add -D vitepress@next vue
```

```sh [bun]
bun add -D vitepress@next
```

:::

---

### 4. أضف المثال البرمجي الخاص بك

#### 4.1 أنشئ ملف المثال

1. أنشئ ملفًا جديدًا في `/docs/examples` باسم لغة البرمجة.
2. يجب أن ينتهي اسم الملف بـ `.md`.
3. قم بتضمين **طريقتين مختلفين على الأقل** لإجراء استدعاءات API.

#### 4.2 أضف المثال إلى الشريط الجانبي

1. افتح `/docs/.vitepress/config.mts`.
2. حدد موقع قسم **"أمثلة البرمجة" (Code Examples)** في الشريط الجانبي.
3. أضف ملفك الجديد إلى القائمة.
4. حافظ على القائمة بالترتيب الأبجدي حسب لغة البرمجة.

---

### 5. ابدأ خادم التطوير

قبل إنشاء طلب سحب (Pull Request)، تحقق محليًا من أن تغييراتك لم تكسر أي شيء.

::: code-group

```sh [npm]
npm run dev
```

```sh [pnpm]
pnpm run dev
```

```sh [yarn]
yarn dev
```

```sh [bun]
bun run dev
```

:::

---

### 6. أنشئ طلب سحب (Pull Request)

قدّم طلب سحب إلى المستودع الأصلي.
