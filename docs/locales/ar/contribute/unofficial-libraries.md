# إضافة مكتبات غير رسمية

## إرشادات المساهمة للمكتبات غير الرسمية

* يجب أن تكون المشاركات **مكتوبة باللغة الإنجليزية**.
* يجب على مالك المكتبة الانضمام إلى [سيرفر Discord](https://nekos.best/discord?ref=docs) الخاص بنا
* يجب أن تتبع المكتبات ممارسات جودة الكود الجيدة.
* يجب **ألا تحتوي** المكتبات على برامج ضارة أو أي سلوك غير آمن آخر.
* يجب أن تكون المكتبة متاحة للعامة ومُدارة بنشاط.
* تقديم تعليمات تثبيت واستخدام واضحة في المستودع الخاص بك.

### نحتفظ بالحق في:

* تعديل مشاركتك بعد المراجعة.
* إزالة مشاركتك إذا أصبحت قديمة أو غير آمنة أو غير صيانة.

## إضافة مكتبة غير رسمية جديدة

### 1. قم بعمل Fork لهذا المستودع

### 2. قم باستنسخ الـ Fork الخاص بك واستخدم `cd` للانتقال إلى دليل المشروع

### 3. قم بتثبيت VitePress

يمكنك العثور على متطلبات VitePress الأساسية في [التوثيق الرسمي](https://vitepress.dev/guide/getting-started#prerequisites).

::: code-group

```sh [npm]
npm add -D vitepress@next
```

```sh [pnpm]
pnpm add -D vitepress@next
```

```sh [yarn]
yarn add -D vitepress@next vue
```

```sh [bun]
bun add -D vitepress@next
```

:::

---

### 4. أضف مكتبتك غير الرسمية إلى الشريط الجانبي

1. افتح `/docs/.vitepress/config.mts`.
2. حدد موقع قسم **"المكتبات غير الرسمية" (Unofficial Libraries)** في الشريط الجانبي.
3. أضف رابطًا إلى مستودع مكتبتك.
4. حافظ على القائمة بالترتيب الأبجدي حسب لغة البرمجة.

---

### 5. ابدأ خادم التطوير

قبل إنشاء طلب سحب (Pull Request)، تحقق محليًا من أن تغييراتك لم تكسر أي شيء.

::: code-group

```sh [npm]
npm run dev
```

```sh [pnpm]
pnpm run dev
```

```sh [yarn]
yarn dev
```

```sh [bun]
bun run dev
```

:::

---

### 6. أنشئ طلب سحب (Pull Request)

قدّم طلب سحب إلى المستودع الأصلي.
