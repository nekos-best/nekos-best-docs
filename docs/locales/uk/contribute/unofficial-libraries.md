# Додавання неофіційних бібліотек

## Правила для неофіційних бібліотек

* Описи **повинні** бути написані англійською мовою.
* Власник бібліотеки повинен приєднатися до нашого [сервера Discord](https://nekos.best/discord?ref=docs)
* Бібліотеки повинні відповідати хорошим практикам якості коду.
* Бібліотеки **не повинні** містити шкідливого ПЗ або іншої небезпечної поведінки.
* Бібліотека повинна бути публічно доступною та активно підтримуватися.
* Надайте чіткі інструкції з встановлення та використання у своєму репозиторії.

### Ми залишаємо за собою право:

* Змінювати ваш матеріал після перегляду.
* Видалити ваш матеріал, якщо він застаріє, стане небезпечним або перестане підтримуватися.

## Додавання нової неофіційної бібліотеки

### 1. Зробіть форк цього репозиторію

### 2. Клонуйте свій форк та перейдіть у каталог проекту за допомогою `cd`

### 3. Встановіть VitePress

Ви можете знайти попередні вимоги VitePress в
[офіційній документації](https://vitepress.dev/guide/getting-started#prerequisites).

::: code-group

```sh [npm]
npm add -D vitepress@next
```

```sh [pnpm]
pnpm add -D vitepress@next
```

```sh [yarn]
yarn add -D vitepress@next vue
```

```sh [bun]
bun add -D vitepress@next
```

:::

---

### 4. Додайте свою неофіційну бібліотеку до бічної панелі

1. Відкрийте `/docs/.vitepress/config.mts`.
2. Знайдіть розділ **"Unofficial Libraries"** у бічній панелі.
3. Додайте посилання на репозиторій вашої бібліотеки.
4. Зберігайте список в алфавітному порядку за назвою мови програмування.

---

### 5. Запустіть сервер розробки

Перед створенням pull request перевірте локально, що ваші зміни нічого не зламали.

::: code-group

```sh [npm]
npm run dev
```

```sh [pnpm]
pnpm run dev
```

```sh [yarn]
yarn dev
```

```sh [bun]
bun run dev
```

:::

---

### 6. Створіть Pull Request

Надішліть pull request до оригінального репозиторію.
