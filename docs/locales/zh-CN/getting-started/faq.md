# 常见问题 (FAQ)

以下列出了最常见的一些问题。

## 常规

#### 服务器位于何处？
> 服务器托管在德国。

#### API 的稳定性与可靠性如何？
> 我们的 API 目前保持每年**至少** 99.99% 的可用性。

#### 使用 API 是否必须标注来源署名？
> 不需要，不强制要求标注署名，但如果您能够标注，我们将非常感谢。

## 图片与 GIF

#### 图片和 GIF 的内容有多安全（SFW）？
> 我们优先保证完全适合工作场所（SFW）的内容。与许多其他动漫 API 不同，您不会在这里找到穿着暗示性/性感服饰的角色（例如泳装、比基尼、内衣、透明衣服或过于暴露的服装）。\
> 此外，我们还会排除诸如露裤（故意露出内衣）、腋下特写“诱导”以及类似偏向特定癖好的内容。\
> 每张图片和 GIF 都经过精挑细选，以确保内容安全与高质量，而非单纯追求数量。

#### 我可以将这些图片或 GIF 用于商业用途吗？
> 不可以。严禁用于商业用途，详见[使用条款](/legal/tos)。\
> 我们并不拥有这些图片的所有权，分享这些内容纯粹出于娱乐目的，并已对原作者进行了恰当的署名。

#### 我必须包含作者的署名信息吗？
> 虽然不强制要求您包含作者署名，但我们强烈建议您这样做，因为 API 已经提供了这些信息。

#### 图片或 GIF 标注了错误或缺失的来源，我应该去哪里反馈？
> 如果您发现 API 中存在错误或缺失的来源信息，请前往我们的 Discord 社区进行反馈。进入 `#api-support` 频道并创建新贴子即可。

#### 能在 API 中添加 X 分类吗？
> 分类建议应通过我们的 Discord 社区提交，我们在那里设有专门的 `#suggestions` 频道。
>
> **注意：** 我们仅接受全年龄/全人群安全（SFW）的分类建议。涉及诸如“舔 (lick)”或“绑架 (kidnap)”等内容不符合我们的 SFW 指南，将被直接拒绝。

#### 何时会发布新的图片、GIF 或分类？
> 没有固定的发布时间表或预计到达时间（ETA）。所有内容均为手动添加，当内容准备就绪且团队成员有个人空闲时间处理时就会更新。

#### 我可以向 API 贡献图片或 GIF 吗？
> 当然可以。如果您想做出贡献，请加入我们的 Discord 社区并在 `#api-support` 频道中提帖。\
> 贡献者将在我们的 Discord 社区中获得专属的 Contributor 身份组。

#### API 中是否有 AI 生成的图片或 GIF？
> 没有。API 中的所有图片和 GIF 均由人类画师创作。我们不支持任何 AI 生成的内容。

## 调试与错误

#### 为什么我会收到 ERR-C 错误代码 "NB-BXIUA"？
> 虽然自 2024 年 8 月起就已封禁空的 `User-Agent` 请求头，但在 2026 年 6 月引入了全新的格式规范。请务必遵循要求的格式，因为使用 HTTP 库的默认值或错误格式可能会导致您的请求被自动拒绝。请查阅我们的 [User-Agent 文档](/zh-CN/getting-started/api-reference.html#user-agent) 以确保您的配置正确。

#### 我使用了 VPN 或代理，但现在无法继续发送请求了。
> 允许使用 VPN 和代理，但存在一些重要限制。它们的 IP 地址由许多用户共享，这意味着单个恶意用户的行为可能导致该 IP 被封禁，从而影响使用该 IP 的其他人。被封禁的 VPN/代理 IP 将被永久封锁，概不例外，且被标记的概率远高于普通 IP。如果您依赖 VPN/代理并失去了访问权限，很遗憾我们对此无能为力。
