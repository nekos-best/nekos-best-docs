# 常见问题 (FAQ)

以下列出了一些最常见的问题。

## 常规

#### 服务器位于哪里？
> 服务器托管在德国。

#### API 的可靠性如何？
> 我们的 API 目前保持每年**至少** 99.99% 的可用性。

#### 使用 API 需要标注来源吗？
> 不需要，署名并非强制要求，但如果你愿意标注，我们会非常感谢。

## 图片与 GIF

#### 图片和 GIF 的安全程度（SFW）如何？
> 我们始终将完全适合工作环境（SFW）的内容放在首位。与许多其他动漫 API 不同，这里不会出现穿着性暗示服饰的角色（例如泳装、比基尼、内衣、透视装或过于暴露的服装）。\
> 此外，我们还会排除走光镜头（刻意露出内衣）、以腋下为主的擦边内容以及类似的癖好向素材。\
> 每张图片和 GIF 都经过人工精挑细选，比起单纯堆砌数量，我们更看重内容的安全与质量。

#### 可以将这些图片或 GIF 用于商业用途吗？
> 不可以。正如我们的[服务条款](/legal/tos)所述，严禁任何商业用途。\
> 我们并不拥有这些图片的版权，所有内容仅作娱乐分享之用，并尽可能附带原作者的署名信息。

#### 必须展示画师的署名信息吗？
> 虽然并不强制要求，但因为 API 本身已经返回了这些信息，我们强烈建议你在应用中一并展示。

#### 发现图片或 GIF 的来源信息有误或缺失，应该去哪里反馈？
> 如果你发现来源信息有误或缺失，请在我们的 Discord 服务器中进入 `#api-support` 频道发帖反馈。

#### 可以向 API 添加某个新分类吗？
> 请通过我们的 Discord 服务器在专门的 `#suggestions` 频道提交分类建议。
>
> **注意：** 我们仅接受符合 SFW 标准的分类建议。涉及 `lick`（舔）或 `kidnap`（绑架）等不符合 SFW 指南的建议会被拒绝。

#### 新的图片、GIF 或分类什么时候更新？
> 没有固定的发布排期或预计上线时间（ETA）。所有内容均为人工审核和添加，通常会在素材准备就绪且维护者有空余时间时陆续更新。

#### 我可以向 API 贡献图片或 GIF 吗？
> 当然可以！如果你想参与贡献，请加入我们的 Discord 服务器并在 `#api-support` 频道发帖。
> 贡献者将在我们的 Discord 社区获得专属的 Contributor 身份组。

#### API 中包含 AI 生成的图片或 GIF 吗？
> 没有。API 中的所有图片和 GIF 均由人类创作者制作，我们不支持任何 AI 生成内容。

#### 可以将图片或 GIF 用于 AI、机器学习（ML）或 LLM 训练吗？
> **不可以。** 如我们的[服务条款](/legal/tos)所述，严禁使用 API 中的内容训练 AI、机器学习或大语言模型（包括抓取数据或构建数据集），违者将被封禁 API 访问权限。由于我们并不拥有这些内容的版权，因此也无法授予任何相关许可。

#### 可以缓存、下载或爬取图片和 GIF 吗？
> 允许缓存 **JSON API 响应**（例如元数据和 URL），但仅限**私人用途**，且不得公开或再分发。\
> 根据我们的[服务条款](/legal/tos)，**严禁**缓存、下载、爬取、转存或批量提取**实际的图片或 GIF 资源文件**，违者将被封禁 API 访问权限。

#### GIF 文件有多大？
> 为了确保快速加载，我们的 GIF 均经过体积优化，每个文件平均大小**约 900 KB**。

## 调试与错误

#### 为什么会收到 ERR-C 错误代码 "NB-BXIUA"？
> 空的或伪造的 `User-Agent` 请求头会被拦截。请确保请求包含有效的 `User-Agent` 请求头，并避免伪造浏览器标识或冒充已知爬虫。推荐格式请参阅 [User-Agent 文档](/zh-CN/getting-started/api-reference.html#user-agent)。

#### 为什么会收到 ERR-C 错误代码 "NB-BCFSD"？
> `NB-BCFSD` 表示你已被我们的自动滥用检测系统封禁了 API 访问权限。如果你认为这是误判，请通过 [Discord 服务器](https://nekos.best/discord)联系我们，或发送邮件至 **[contact@nekos.best](mailto:contact@nekos.best)**。

#### 为什么会收到 ERR-C 错误代码 "NB-BXASN"？
> `NB-BXASN` 表示你所在的 ASN（自治系统编号）在我们的系统中处于封禁状态。如需继续发送请求，需要将你的 IP 地址加入白名单。请通过 [Discord 服务器](https://nekos.best/discord)或发送邮件至 **[contact@nekos.best](mailto:contact@nekos.best)** 联系我们。

#### 我在使用 VPN 或代理，但现在无法继续发送请求了。
> 我们允许使用 VPN 和代理，但这存在一些重要限制。由于它们的 IP 地址由大量用户共享，只要有一名恶意用户触发封禁，同一 IP 下的所有用户都会受到影响。被封禁的 VPN/代理 IP 将被永久封锁且不设例外，同时被系统标记的概率也远高于普通 IP。如果你依赖 VPN 或代理而失去访问权限，很遗憾我们对此无能为力。
