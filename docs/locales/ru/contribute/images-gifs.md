# Добавление изображений и GIF

## Требования к контенту

1. **Высокое качество:** Изображения и GIF должны быть четкими, без сильного сжатия.
2. **Строго SFW:** Принимается только контент Safe For Work.
3. **Указание автора:** Обязательно укажите имя автора и ссылку на оригинал (при наличии).
4. **Способ отправки:** Вы можете присоединиться к нашему [Discord-серверу](https://nekos.best/discord?ref=docs) и отправить файлы в специальный канал или создать Pull Request на GitHub.
