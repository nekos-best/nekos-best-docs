# Häufig gestellte Fragen (FAQ)

Nachfolgend finden Sie einige der am häufigsten gestellten Fragen.

## Allgemein

#### Wo befindet sich der Server?
> Der Server wird in Deutschland gehostet.

#### Wie zuverlässig ist die API?
> Unsere API verzeichnet derzeit eine Erreichbarkeit von **mindestens** 99,99 % pro Jahr.

#### Ist eine Quellenangabe (Attribution) für die Nutzung der API erforderlich?
> Nein, eine Quellenangabe ist nicht zwingend erforderlich, wird aber sehr geschätzt.

## Bilder & GIFs

#### Wie sicher bzw. jugendfrei sind die Bilder und GIFs?
> Wir legen großen Wert auf absolut jugendfreie Inhalte (Safe-for-Work). Im Gegensatz zu vielen anderen Anime-APIs finden Sie bei uns keine Charaktere in freizügigen Outfits (z. B. Badeanzüge, Bikinis, Unterwäsche, transparente Kleidung oder übermäßig freizügige Kleidung).\
> Zudem schließen wir Inhalte wie Panty-Shots (bei denen Unterwäsche absichtlich gezeigt wird), achselorientierten „Bait“ und ähnliche fetischbezogene Inhalte aus.\
> Jedes Bild und GIF wird sorgfältig ausgewählt, um sichere und hochwertige Inhalte statt bloßer Quantität zu gewährleisten.

#### Kann ich die Bilder oder GIFs kommerziell nutzen?
> Nein. Die kommerzielle Nutzung ist gemäß unseren [Nutzungsbedingungen](/legal/tos) untersagt.\
> Die Bilder gehören nicht uns und werden rein zu Unterhaltungszwecken geteilt, mit entsprechenden Verweisen auf die ursprünglichen Urheber.

#### Bin ich verpflichtet, die Urheberangaben der Künstler einzubinden?
> Obwohl Sie nicht verpflichtet sind, die Urheberangaben der Künstler einzubinden, empfehlen wir dies dringend, da die API diese Informationen bereits bereitstellt.

#### Für ein Bild oder GIF ist eine falsche oder fehlende Quelle angegeben. Wo kann ich das melden?
> Wenn Ihnen in der API eine falsche oder fehlende Quelle auffällt, melden Sie dies bitte auf unserem Discord-Server. Gehen Sie in den Kanal `#api-support` und erstellen Sie einen neuen Beitrag.

#### Könnt ihr X zur API hinzufügen?
> Vorschläge für Kategorien sollten über unseren Discord-Server eingereicht werden, wo wir einen eigenen Kanal für `#suggestions` haben.
>
> **Hinweis:** Es werden nur jugendfreie (SFW) Kategorievorschläge akzeptiert. Vorschläge mit Inhalten wie „Lecken“ oder „Entführen“ entsprechen nicht unseren SFW-Richtlinien und werden abgelehnt.

#### Wann werden neue Bilder, GIFs oder Kategorien veröffentlicht?
> Es gibt keinen festen Veröffentlichungsplan oder geschätzten Zeitrahmen (ETA). Alle Inhalte werden manuell hinzugefügt, und Updates erfolgen, wenn sie fertig sind und die Eigentümer die entsprechende Zeit dafür haben.

#### Kann ich Bilder oder GIFs zur API beisteuern?
> Absolut. Wenn Sie etwas beitragen möchten, treten Sie bitte unserem Discord-Server bei und erstellen Sie einen Beitrag in `#api-support`.\
> Mitwirkende erhalten in unserer Discord-Community eine spezielle Contributor-Rolle.

#### Gibt es KI-generierte Bilder oder GIFs in der API?
> Nein. Alle Bilder und GIFs in der API wurden von menschlichen Künstlern erstellt. Wir unterstützen keine KI-generierten Inhalte.

## Fehlerbehebung

#### Warum erhalte ich den ERR-C-Code "NB-BXIUA"?
> Während leere `User-Agent`-Header bereits seit August 2024 blockiert werden, wurden im Juni 2026 neue Formatierungsrichtlinien eingeführt. Stellen Sie sicher, dass Sie dem geforderten Format folgen, da die Verwendung von Bibliotheks-Standardwerten oder einem falschen Format dazu führen kann, dass Ihre Anfragen automatisch abgelehnt werden. Bitte lesen Sie unsere [User-Agent-Dokumentation](/de/getting-started/api-reference.html#user-agent), um sicherzustellen, dass Ihre Konfiguration korrekt ist.

#### Ich nutze ein VPN oder einen Proxy, kann aber jetzt keine Anfragen mehr stellen.
> VPNs und Proxys sind erlaubt, bringen jedoch einige wichtige Einschränkungen mit sich. Ihre IP-Adressen werden von vielen Nutzern geteilt, was bedeutet, dass ein einziger schlechter Akteur dazu führen kann, dass eine IP gesperrt wird und alle anderen betrifft, die sie nutzen. Gesperrte VPN-/Proxy-IPs werden dauerhaft und ohne Ausnahmen blockiert und wesentlich häufiger geflaggt als reguläre IPs. Wenn Sie auf einen VPN/Proxy angewiesen sind und den Zugriff verlieren, können wir leider nichts dagegen tun.
