# 자주 묻는 질문 (FAQ)

가장 자주 묻는 질문과 답변을 정리했습니다.

## 일반

#### 서버는 어디에 위치해 있나요?
> 서버는 독일에 호스팅되어 있습니다.

#### API는 얼마나 안정적인가요?
> 현재 연간 **최소** 99.99% 이상의 가동률을 유지하고 있습니다.

#### API 사용 시 출처 표기가 필수인가요?
> 아니요, 필수는 아니지만 표기해 주시면 감사하겠습니다.

## 이미지 & GIF

#### 이미지와 GIF는 얼마나 안전한가요(SFW)?
> 완전한 SFW(Safe-For-Work) 콘텐츠를 최우선으로 합니다. 다른 많은 애니메이션 API와 달리 수영복, 비키니, 속옷, 비치는 의상, 과도한 노출이 있는 캐릭터는 포함하지 않습니다.\
> 또한 속옷이 의도적으로 보이는 구도, 겨드랑이 강조 연출 및 이와 유사한 페티시 성향의 콘텐츠도 제외합니다.\
> 단순한 수량보다 안전하고 높은 품질을 유지하기 위해 모든 이미지와 GIF를 꼼꼼히 선별합니다.

#### 이미지나 GIF를 상업적으로 사용할 수 있나요?
> 아니요. [이용약관](/legal/tos)에 명시된 바와 같이 상업적 이용은 금지되어 있습니다.\
> 이미지의 저작권은 저희에게 있지 않으며, 원작자에게 적절한 출처를 표기한 상태로 순수 오락 목적에 한해 공유됩니다.

#### 아티스트 출처 정보를 반드시 표시해야 하나요?
> 필수는 아니지만, API 응답에 이미 출처 정보가 포함되어 있으므로 함께 표시하는 것을 강력히 권장합니다.

#### 이미지나 GIF의 출처가 잘못되었거나 누락되었습니다. 어디에 제보하나요?
> 잘못되었거나 누락된 출처를 발견하셨다면 Discord 서버의 `#api-support` 채널에 새 게시글을 작성해 제보해 주세요.

#### API에 원하는 카테고리를 추가해 줄 수 있나요?
> 카테고리 제안은 Discord 서버의 전용 `#suggestions` 채널을 통해 제출해 주세요.
>
> **참고:** SFW 카테고리 제안만 접수합니다. `lick`(핥기)이나 `kidnap`(납치)처럼 SFW 가이드라인에 어긋나는 제안은 거절됩니다.

#### 새로운 이미지, GIF 또는 카테고리는 언제 추가되나요?
> 정해진 업데이트 일정이나 예상 시기(ETA)는 없습니다. 모든 콘텐츠는 수동으로 추가되며, 준비가 완료되고 운영진의 개인 시간이 확보될 때 업데이트됩니다.

#### API에 이미지나 GIF를 기여할 수 있나요?
> 물론입니다! 기여를 원하신다면 Discord 서버에 참여해 `#api-support` 채널에 글을 남겨 주세요.
> 기여해 주신 분들께는 Discord 커뮤니티에서 특별한 Contributor 역할을 부여해 드립니다.

#### API에 AI로 생성된 이미지나 GIF가 포함되어 있나요?
> 아니요. API의 모든 이미지와 GIF는 사람 아티스트가 제작한 작품이며, AI 생성 콘텐츠는 지원하지 않습니다.

#### 이미지나 GIF를 AI, 머신러닝(ML) 또는 LLM 학습에 사용할 수 있나요?
> **아니요.** [이용약관](/legal/tos)에 따라 API의 콘텐츠를 AI, 머신러닝 또는 LLM 모델 학습에 사용하는 행위(데이터셋 수집 및 스크래핑 포함)는 엄격히 금지되며, 적발 시 API가 차단됩니다. 저희는 콘텐츠의 저작권자가 아니므로 별도의 사용 허가도 제공할 수 없습니다.

#### 이미지나 GIF를 캐싱, 다운로드 또는 스크래핑해도 되나요?
> 메타데이터와 URL 같은 **JSON API 응답**은 공개하거나 재배포하지 않는 **개인 용도**에 한해 캐싱할 수 있습니다.\
> 반면 **실제 이미지 및 GIF 에셋**을 캐싱, 다운로드, 스크래핑, 재호스팅 또는 대량 추출하는 행위는 [이용약관](/legal/tos)에 따라 **엄격히 금지**되며, 위반 시 API가 차단됩니다.

#### GIF 파일 크기는 어느 정도인가요?
> 빠른 로딩을 위해 모든 GIF를 작고 가볍게 최적화하고 있으며, 파일당 평균 **약 900 KB** 수준입니다.

## 디버깅 / 오류

#### ERR-C 코드 "NB-BXIUA"가 발생하는 이유는 무엇인가요?
> 비어 있거나 스푸핑된 `User-Agent` 헤더는 차단됩니다. 유효한 `User-Agent` 헤더를 포함해 요청하고, 브라우저 문자열을 위장하거나 알려진 크롤러를 사칭하지 않도록 주의하세요. 권장 형식은 [User-Agent 문서](/ko/getting-started/api-reference.html#user-agent)에서 확인할 수 있습니다.

#### ERR-C 코드 "NB-BCFSD"가 발생하는 이유는 무엇인가요?
> `NB-BCFSD`는 자동 어뷰징 탐지 시스템에 의해 API 사용이 차단되었음을 의미합니다. 오탐이라고 생각되시면 [Discord 서버](https://nekos.best/discord) 또는 이메일(**[contact@nekos.best](mailto:contact@nekos.best)**)로 문의해 주세요.

#### ERR-C 코드 "NB-BXASN"이 발생하는 이유는 무엇인가요?
> `NB-BXASN`은 사용 중인 ASN(자율 시스템 번호)이 시스템에서 차단되었음을 의미합니다. 요청을 보내려면 IP 주소를 화이트리스트에 등록해야 합니다. [Discord 서버](https://nekos.best/discord) 또는 이메일(**[contact@nekos.best](mailto:contact@nekos.best)**)로 문의해 주세요.

#### VPN이나 프록시를 사용 중인데 더 이상 요청을 보낼 수 없습니다.
> VPN과 프록시 사용 자체는 허용되지만 몇 가지 중요한 제한이 있습니다. IP 주소를 여러 사용자가 공유하기 때문에 단 한 명의 악성 사용자로 인해 해당 IP가 차단되면 같은 IP를 쓰는 모든 사용자가 영향을 받게 됩니다. 차단된 VPN/프록시 IP는 예외 없이 영구 차단되며, 일반 IP보다 훨씬 높은 비율로 탐지됩니다. 이로 인해 접근이 차단된 경우 안타깝게도 별도 조치가 어렵습니다.
