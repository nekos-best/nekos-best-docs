# 常見問題（FAQ）

以下整理了開發者最常詢問的問題。

## 一般問題

#### 伺服器位於哪裡？
> 伺服器託管於德國。

#### API 的穩定度如何？
> 我們的 API 目前每年維持 **至少** 99.99% 的正常運作時間（uptime）。

#### 使用 API 需要標註出處嗎？
> 不需要強制標註出處，但如果你願意標註，我們會非常感謝。

## 圖片與 GIF

#### 圖片與 GIF 的安全程度（SFW）如何？
> 我們堅持提供完全適合公開與工作場合（SFW）的內容。與許多其他動漫 API 不同，這裡不會出現穿著具性暗示服裝的角色（例如泳裝、比基尼、內衣、透視裝或過度暴露的服裝）。\
> 此外，我們也排除走光照（刻意露出內衣）、刻意聚焦特定部位的擦邊畫面，以及其他偏向性癖導向的內容。\
> 每一張圖片與 GIF 都經過人工仔細挑選，重視安全與品質，而非單純追求數量。

#### 我可以將圖片或 GIF 用於商業用途嗎？
> 不可以。依據我們的[服務條款](/legal/tos)，嚴禁任何商業用途。\
> 這些圖片的版權並不屬於我們，僅出於娛樂目的分享，並已妥善標註原創作者資訊。

#### 我必須顯示繪師的標註資訊嗎？
> 雖然不強制要求，但我們強烈建議你顯示繪師標註，因為 API 回應中已經提供了這些資訊。

#### 圖片或 GIF 的來源資訊有誤或缺失，我該在哪裡回報？
> 如果你發現 API 中的來源資訊有誤或缺少，歡迎到我們的 Discord 伺服器回報。只要前往 `#api-support` 頻道建立新貼文即可。

#### 可以請你們新增 X 分類到 API 嗎？
> 歡迎透過我們 Discord 伺服器中的專屬 `#suggestions` 頻道提出分類建議。
>
> **注意：** 我們僅接受 SFW（全年齡）分類建議。涉及舔（lick）或綁架（kidnap）等內容的提案不符合我們的 SFW 規範，將會被拒絕。

#### 新的圖片、GIF 或分類何時會更新？
> 我們沒有固定的更新排程或預計釋出時間（ETA）。所有內容皆由人工手動整理與新增，會在準備完成且維護者有空閒時間時陸續更新。

#### 我可以為 API 貢獻圖片或 GIF 嗎？
> 當然可以！如果你想一起貢獻內容，歡迎加入我們的 Discord 伺服器，並在 `#api-support` 建立貼文。
> 貢獻者也會在我們的 Discord 社群獲得專屬的 Contributor 身分組。

#### API 裡有 AI 生成的圖片或 GIF 嗎？
> 沒有。API 中的所有圖片與 GIF 皆由人類繪師創作，我們不收錄也不支援 AI 生成內容。

#### 我可以將圖片或 GIF 用於 AI、機器學習或 LLM 訓練嗎？
> **不可以。** 依據我們的[服務條款](/legal/tos)，嚴格禁止將 API 的任何內容用於訓練 AI、機器學習或大型語言模型（LLM）（包括爬取或蒐集資料集），違者將遭到 API 封鎖。由於我們並不擁有這些內容的版權，因此也無法授予相關授權。

#### 我可以快取、下載或爬取圖片或 GIF 嗎？
> 快取 **JSON API 回應**（例如中繼資料與 URL）僅允許用於**私人用途**，前提是不得公開或重新散佈。\
> 依據我們的[服務條款](/legal/tos)，嚴格禁止對**實際的圖片或 GIF 檔案**進行快取、下載、爬取、重新託管或批次擷取，違者將遭到 API 封鎖。

#### GIF 的檔案大小大約是多少？
> 我們的 GIF 皆經過最佳化與精簡以加快載入速度，平均每個檔案約 **~900 KB**。

## 偵錯與錯誤

#### 為什麼會收到 ERR-C 代碼「NB-BXIUA」？
> 空的或偽造的 `User-Agent` 標頭會遭到封鎖。請確認你的請求包含有效的 `User-Agent` 標頭，並避免偽造瀏覽器字串或冒充已知爬蟲。建議格式請參閱我們的 [User-Agent 文件](/zh-TW/getting-started/api-reference.html#user-agent)。

#### 為什麼會收到 ERR-C 代碼「NB-BCFSD」？
> `NB-BCFSD` 表示你因觸發我們的自動濫用偵測系統而遭到 API 封鎖。如果你認為這是誤判，請透過我們的 [Discord 伺服器](https://nekos.best/discord)或寄信至 **[contact@nekos.best](mailto:contact@nekos.best)** 與我們聯絡。

#### 為什麼會收到 ERR-C 代碼「NB-BXASN」？
> `NB-BXASN` 表示你的 ASN（自治系統編號）在我們的系統中被封鎖了。若要發送請求，需要先將你的 IP 位址加入白名單。請透過我們的 [Discord 伺服器](https://nekos.best/discord)或寄信至 **[contact@nekos.best](mailto:contact@nekos.best)** 與我們聯絡。

#### 我使用 VPN 或代理伺服器，但現在無法發送請求了。
> 我們允許使用 VPN 與代理伺服器，但這類服務有一些重要限制。由於它們的 IP 位址由大量使用者共用，只要有一名惡意使用者導致該 IP 被封鎖，就會連帶影響所有共用者。遭到封鎖的 VPN／代理伺服器 IP 會永久封鎖且不予例外，且被系統標記的機率也遠高於一般 IP。如果你因依賴 VPN／代理伺服器而失去存取權限，很遺憾我們無法提供協助。
