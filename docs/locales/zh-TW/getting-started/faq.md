# 常見問題 (FAQ)

以下列出了一些最常被問到的問題。

## 一般問題

#### 伺服器設在哪裡？
> 伺服器託管於德國。

#### API 的穩定度如何？
> 我們的 API 目前每年保持 **至少** 99.99% 的正常運作時間。

#### 使用 API 是否需要標註出處？
> 不需要，使用 API 不需要強制標註出處，但如果您標註了我們將非常感謝。

## 圖片與 GIF

#### 圖片與 GIF 有多安全（SFW）？
> 我們優先提供完全適合工作場所（Safe-For-Work）的內容。與其他許多動漫 API 不同，您不會在這裡找到穿著暗示性暴露服裝（例如泳裝、比基尼、內衣、透視裝或過度暴露服裝）的角色。\
> 此外，我們排除走光照（故意露出內衣）、特定部位誘惑鏡頭以及類似的性癖導向內容。\
> 每張圖片與 GIF 都經過精心挑選，以確保提供安全且高品質的內容，而非盲目追求數量。

#### 我可以將圖片或 GIF 用於商業用途嗎？
> 不可以。如[服務條款](/legal/tos)中所述，嚴禁商業用途。\
> 圖片的版權不屬於我們，僅出於娛樂目的分享，並已適當標註原創作者。

#### 我是否必須包含繪師的標註資訊？
> 雖然不強制要求包含繪師標註，但我們強烈建議您這麼做，因為 API 已經提供了這些資訊。

#### 圖片或 GIF 的來源標註有誤或缺失，我該在哪裡回報？
> 如果您發現 API 中的來源標註有誤或缺失，請至我們的 Discord 伺服器進行回報。前往 `#api-support` 頻道並建立新文章即可。

#### 您能在 API 中新增 X 分類嗎？
> 分類建議應透過我們的 Discord 伺服器提交，我們在該處設有專門的 `#suggestions` 頻道。
>
> **注意：** 僅接受 SFW（全年齡）分類建議。涉及舔（lick）或綁架（kidnap）等內容的建議不符合我們的 SFW 規範，將會被拒絕。

#### 何時會發布新的圖片、GIF 或分類？
> 我們沒有固定的發布時程表或預計完成時間（ETA）。所有內容皆為人工手動新增，當內容準備就緒且擁有者有個人空閒時間進行處理時，就會進行更新。

#### 我可以為 API 貢獻圖片或 GIF 嗎？
> 當然可以。如果您想進行貢獻，請加入我們的 Discord 伺服器並在 `#api-support` 中建立文章。
> 貢獻者將在我們的 Discord 社群中獲得特殊的 Contributor 身分組。

#### API 中是否有 AI 生成的圖片或 GIF？
> 沒有。API 中的所有圖片與 GIF 皆由人類繪師創作。我們不支援 AI 生成的內容。

## 偵錯與錯誤

#### 為什麼我會收到 ERR-C 代碼 "NB-BXIUA"？
> 雖然空的 `User-Agent` 標頭自 2024 年 8 月起就已被封鎖，但新的格式規範已於 2026 年 6 月推出。請務必遵守要求的格式，因為使用函式庫預設值或不正確的格式可能會導致您的請求被自動拒絕。請檢閱我們的 [User-Agent 文件](/zh-TW/getting-started/api-reference.html#user-agent)以確保您的設定正確。

#### 我使用 VPN 或代理伺服器，但現在無法發送請求了。
> 允許使用 VPN 與代理伺服器，但有一些重要的限制。它們的 IP 地址由許多使用者共用，這意味著只要有一個不良使用者導致 IP 被封鎖，就會影響到使用該 IP 的其他所有人。被封鎖的 VPN/代理伺服器 IP 會被永久封鎖且無例外，並且被標記的機率遠高於一般 IP。若您依賴 VPN/代理伺服器且失去存取權限，很遺憾我們無法為您進行任何處置。
