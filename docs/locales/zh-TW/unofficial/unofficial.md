# 非官方函式庫

---

下方連結的函式庫是由第三方貢獻者所製作。雖然我們在提交過程中會檢查其程式碼品質，但我們無法保證其安全性或持續維護性。

如果範例或其維護者存在任何問題，請在我們的儲存庫中開立[新的 Issue](https://github.com/nekos-best/nekos-best-docs/issues/new?labels=e-issue,d-issue)。若您在使用範例時遇到困難，請聯絡該範例的維護者或加入 [Discord 伺服器](https://nekos.best/discord?ref=docs)。
