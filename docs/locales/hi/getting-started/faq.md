# अक्सर पूछे जाने वाले सवाल (FAQ)

नीचे कुछ सबसे ज़्यादा पूछे जाने वाले सवालों के जवाब दिए गए हैं।

## सामान्य

#### सर्वर कहां स्थित है?
> सर्वर जर्मनी में होस्ट किया गया है।

#### यह API कितना भरोसेमंद है?
> हमारा API वर्तमान में सालाना **कम से कम** 99.99% अपटाइम बनाए रखता है।

#### क्या API का उपयोग करने के लिए क्रेडिट (attribution) देना ज़रूरी है?
> नहीं, क्रेडिट देना अनिवार्य नहीं है, लेकिन अगर आप देते हैं तो हम इसकी सराहना करते हैं।

## इमेज और GIF

#### ये इमेज और GIF कितने सुरक्षित (SFW) हैं?
> हम पूरी तरह safe-for-work (SFW) कंटेंट को प्राथमिकता देते हैं। कई अन्य एनीमे APIs के उलट, यहां आपको आपत्तिजनक या उत्तेजक कपड़ों (जैसे स्विमसूट, बिकिनी, अंडरवियर, पारदर्शी या अत्यधिक रिवीलिंग कपड़े) वाले कैरेक्टर नहीं मिलेंगे।\
> इसके अलावा, हम पैंटी शॉट्स (जहां अंडरवियर जानबूझकर दिखाई देता है), आर्मपिट-फोकस्ड "बेट" और इसी तरह के फेटिश-आधारित कंटेंट को भी शामिल नहीं करते।\
> हर इमेज और GIF को ध्यान से चुना जाता है ताकि केवल मात्रा के बजाय सुरक्षित और उच्च-गुणवत्ता वाला कंटेंट मिले।

#### क्या मैं इमेज या GIF का व्यावसायिक (commercial) उपयोग कर सकता हूं?
> नहीं। हमारी [सेवा की शर्तें](/legal/tos) के अनुसार व्यावसायिक उपयोग प्रतिबंधित है।\
> इन इमेज का स्वामित्व हमारे पास नहीं है और इन्हें केवल मनोरंजन के उद्देश्य से, मूल क्रिएटर्स को उचित श्रेय देते हुए साझा किया जाता है।

#### क्या मुझे आर्टिस्ट का क्रेडिट दिखाना ज़रूरी है?
> हालांकि आर्टिस्ट का क्रेडिट शामिल करना अनिवार्य नहीं है, फिर भी हम इसकी पुरज़ोर सिफारिश करते हैं क्योंकि API पहले से ही यह जानकारी उपलब्ध कराता है।

#### किसी इमेज या GIF का सोर्स गलत है या गायब है। मैं इसकी रिपोर्ट कहां करूं?
> यदि आपको API में कोई गलत या गायब सोर्स दिखाई देता है, तो कृपया हमारे Discord सर्वर में इसकी रिपोर्ट करें। `#api-support` चैनल में जाएं और एक नई पोस्ट बनाएं।

#### क्या आप API में X जोड़ सकते हैं?
> नई कैटेगरी के सुझाव हमारे Discord सर्वर के ज़रिए दिए जाने चाहिए, जहां इसके लिए एक समर्पित `#suggestions` चैनल है।
>
> **नोट:** केवल SFW कैटेगरी के सुझाव ही स्वीकार किए जाते हैं। `lick` या `kidnap` जैसे कंटेंट से जुड़े सुझाव हमारे SFW दिशानिर्देशों के अनुरूप नहीं हैं और उन्हें अस्वीकार कर दिया जाएगा।

#### नई इमेज, GIF या कैटेगरी कब रिलीज़ होंगी?
> कोई निश्चित रिलीज़ शेड्यूल या ETA नहीं है। सारा कंटेंट मैन्युअल रूप से जोड़ा जाता है, और अपडेट तब किए जाते हैं जब वे तैयार हों और ओनर्स के पास काम करने के लिए व्यक्तिगत समय उपलब्ध हो।

#### क्या मैं API में इमेज या GIF का योगदान कर सकता हूं?
> बिल्कुल। यदि आप योगदान करना चाहते हैं, तो कृपया हमारे Discord सर्वर से जुड़ें और `#api-support` में एक पोस्ट बनाएं।
> योगदानकर्ताओं को हमारी Discord कम्युनिटी में एक विशेष Contributor रोल मिलता है।

#### क्या API में AI से बनी इमेज या GIF हैं?
> नहीं। API में मौजूद सभी इमेज और GIF इंसानी आर्टिस्ट्स द्वारा बनाई गई हैं। हम AI-जनरेटेड कंटेंट का समर्थन नहीं करते।

#### क्या मैं इमेज या GIF का उपयोग AI, ML या LLM ट्रेनिंग के लिए कर सकता हूं?
> **नहीं।** जैसा कि हमारी [सेवा की शर्तें](/legal/tos) में स्पष्ट किया गया है, API के कंटेंट का उपयोग AI, मशीन लर्निंग या LLM मॉडल्स को ट्रेन करने के लिए (जिसमें स्क्रैपिंग या डेटासेट एकत्र करना शामिल है) सख्ती से प्रतिबंधित है और ऐसा करने पर API बैन लगाया जाएगा। हम इसकी अनुमति नहीं दे सकते, क्योंकि कंटेंट का स्वामित्व हमारे पास नहीं है।

#### क्या मैं इमेज या GIF को कैश, डाउनलोड या स्क्रैप कर सकता हूं?
> **JSON API रिस्पॉन्स** (जैसे मेटाडेटा और URL) को केवल **व्यक्तिगत उपयोग** के लिए कैश करने की अनुमति है, बशर्ते उन्हें सार्वजनिक न किया जाए या पुनः वितरित (redistribute) न किया जाए।\
> **वास्तविक इमेज या GIF एसेट्स** को कैश करना, डाउनलोड करना, स्क्रैप करना, रीहोस्ट करना या थोक में एक्सट्रैक्ट करना हमारी [सेवा की शर्तें](/legal/tos) के अनुसार **सख्ती से प्रतिबंधित** है और इसके परिणामस्वरूप API बैन लगाया जाएगा।

#### GIF फाइलों का आकार कितना होता है?
> तेज़ लोडिंग के लिए हमारे GIF छोटे और ऑप्टिमाइज़्ड रखे जाते हैं — औसतन प्रत्येक फाइल लगभग **~900 KB** की होती है।

## डीबगिंग / एरर

#### मुझे ERR-C कोड "NB-BXIUA" क्यों मिल रहा है?
> खाली या स्पूफ किए गए `User-Agent` हेडर्स ब्लॉक कर दिए जाते हैं। सुनिश्चित करें कि आपकी रिक्वेस्ट में एक वैध `User-Agent` हेडर शामिल हो, और ब्राउज़र स्ट्रिंग्स को स्पूफ करने या जाने-माने क्रॉलर्स की नकल करने से बचें। सुझाए गए फॉर्मेट के लिए कृपया हमारा [User-Agent डॉक्यूमेंटेशन](/hi/getting-started/api-reference.html#user-agent) देखें।

#### मुझे ERR-C कोड "NB-BCFSD" क्यों मिल रहा है?
> `NB-BCFSD` का मतलब है कि हमारे ऑटोमेटेड अब्यूज़ डिटेक्शन ने आपको API से बैन कर दिया है। यदि आपको लगता है कि यह गलती से हुआ है, तो कृपया हमारे [Discord सर्वर](https://nekos.best/discord) के ज़रिए संपर्क करें या हमें **[contact@nekos.best](mailto:contact@nekos.best)** पर ईमेल करें।

#### मुझे ERR-C कोड "NB-BXASN" क्यों मिल रहा है?
> `NB-BXASN` का मतलब है कि आपका ASN (Autonomous System Number) हमारे सिस्टम में बैन है। रिक्वेस्ट भेजने के लिए आपके IP पते को व्हाइटलिस्ट कराना होगा। कृपया हमारे [Discord सर्वर](https://nekos.best/discord) के ज़रिए संपर्क करें या हमें **[contact@nekos.best](mailto:contact@nekos.best)** पर ईमेल करें।

#### मैं VPN या प्रॉक्सी इस्तेमाल करता हूं, लेकिन अब रिक्वेस्ट नहीं भेज पा रहा हूं।
> VPN और प्रॉक्सी की अनुमति है, लेकिन इनकी कुछ महत्वपूर्ण सीमाएं हैं। इनके IP पते कई यूज़र्स के बीच साझा होते हैं, जिसका मतलब है कि एक भी गलत गतिविधि करने वाला यूज़र उस IP को बैन करा सकता है और उसका असर बाकी सभी यूज़र्स पर पड़ता है। बैन किए गए VPN/प्रॉक्सी IP बिना किसी अपवाद के स्थायी रूप से ब्लॉक कर दिए जाते हैं, और सामान्य IP की तुलना में इनके फ्लैग होने की दर काफी अधिक होती है। यदि आप VPN या प्रॉक्सी पर निर्भर हैं और आपका एक्सेस बंद हो जाता है, तो दुर्भाग्य से हम इसमें कुछ नहीं कर सकते।
