# अनौपचारिक लाइब्रेरीज़ जोड़ना

## अनौपचारिक लाइब्रेरीज़ के लिए योगदान दिशानिर्देश

* सबमिशन अंग्रेज़ी में **अनिवार्य रूप से** लिखे होने चाहिए।
* लाइब्रेरी के मालिक को हमारे [Discord सर्वर](https://nekos.best/discord?ref=docs) से जुड़ना आवश्यक है।
* लाइब्रेरीज़ में अच्छी कोड गुणवत्ता (code quality) के मानकों का पालन होना चाहिए।
* लाइब्रेरीज़ में मैलवेयर या कोई अन्य असुरक्षित व्यवहार **नहीं** होना चाहिए।
* लाइब्रेरी सार्वजनिक रूप से उपलब्ध और सक्रिय रूप से मेंटेन की गई होनी चाहिए।
* अपनी रिपॉजिटरी में इंस्टॉलेशन और उपयोग के स्पष्ट निर्देश दें।

### हमारे पास निम्नलिखित अधिकार सुरक्षित हैं:

* रिव्यू के बाद आपके सबमिशन में बदलाव करना।
* यदि सबमिशन पुराना, असुरक्षित या अनमेंटेंड हो जाए, तो उसे हटाना।

## नई अनौपचारिक लाइब्रेरी जोड़ना

### 1. इस रिपॉजिटरी को Fork करें

### 2. अपने fork को क्लोन करें और प्रोजेक्ट डायरेक्टरी में `cd` करें

### 3. VitePress इंस्टॉल करें

आप VitePress की पूर्वापेक्षाएं (prerequisites)
[आधिकारिक डॉक्यूमेंटेशन](https://vitepress.dev/guide/getting-started#prerequisites) में देख सकते हैं।

::: code-group

```sh [npm]
npm add -D vitepress@next
```

```sh [pnpm]
pnpm add -D vitepress@next
```

```sh [yarn]
yarn add -D vitepress@next vue
```

```sh [bun]
bun add -D vitepress@next
```

:::

---

### 4. अपनी अनौपचारिक लाइब्रेरी को साइडबार में जोड़ें

1. `/docs/.vitepress/config.mts` खोलें।
2. साइडबार में **"Unofficial Libraries"** सेक्शन ढूंढें।
3. अपनी लाइब्रेरी की रिपॉजिटरी का लिंक जोड़ें।
4. सूची को प्रोग्रामिंग भाषा के अनुसार वर्णमाला क्रम (alphabetical order) में रखें।

---

### 5. डेवलपमेंट सर्वर शुरू करें

पुल रिक्वेस्ट बनाने से पहले लोकल रूप से जांच लें कि आपके बदलावों से कुछ टूटा तो नहीं है।

::: code-group

```sh [npm]
npm run dev
```

```sh [pnpm]
pnpm run dev
```

```sh [yarn]
yarn dev
```

```sh [bun]
bun run dev
```

:::

---

### 6. पुल रिक्वेस्ट बनाएं

मूल रिपॉजिटरी में एक पुल रिक्वेस्ट सबमिट करें।
