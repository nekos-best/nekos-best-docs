# Introdução

## Sobre nós

Olá! Boas-vindas à documentação para desenvolvedores da **NEKOSBEST**.

Estamos no ar desde **fevereiro de 2021**, servindo imagens e GIFs de anime de alta qualidade, seguros para todos os públicos (SFW), em várias categorias e com baixa latência.
